My old website was a single hand-written HTML page: a headshot, a few boxes for work experience, and three student projects. It no longer matched my résumé, so I rebuilt it.

![The social preview image for the new site](/images/og.jpg)

## The stack

The site is a [Next.js](https://nextjs.org) app using the App Router, with [shadcn/ui](https://ui.shadcn.com) components on Tailwind CSS v4. It is exported as plain static files, so it can be hosted for free on GitHub Pages with my own domain and HTTPS.

<Callout title="Static export">
  There is no server. Every page, including each blog post, is rendered to HTML
  at build time.
</Callout>

## Content lives in the repo

My experience, skills, education and projects are typed data files, so the home page and the résumé page read from the same source. Posts like this one are MDX files, which means I can write Markdown and drop in React components when a post needs one.

Code blocks are highlighted at build time, with no client-side JavaScript:

```ts title="src/lib/posts.ts"
export async function getPost(slug: string) {
  return (await getAllPosts()).find((post) => post.slug === slug);
}
```

## Deploying

Pull requests run lint, typecheck and build checks. Merging into the `develop` branch publishes a preview under `/develop`, and merging into `master` updates the live site. Both are built and published together, because GitHub Pages serves one site per repository.

You can read the rest of the site on the [projects page](/projects/) or take a look at the [source on GitHub](https://github.com/MichelGeorgesNajarian/mgnajarian.com).
